# ProofGraph adapter handoff draft — HeaderLens v15 (UNIMPLEMENTED)

ProofGraph's HeaderLens adapter remains an **unbuilt design**, not a finished platform. This handoff should be treated as a strict proposed ingest contract, not network authorization.

1. **Version compatibility and deterministic replay:** accept exactly registered schema identities; validate v15 JSON Schema; verify v15 normalized observation SHA-256 with independent `tools/verify_evidence_v15.py`. Archived v14/v13 evidence uses its historical verifier. Never mutate or silently upgrade old evidence; reject future unknown version identities until a signed migration/adapter exists.
2. **Typed Security IR:** separate observed target/final URL, HTTP status/version, redirect/interim request occurrences, headers, redaction flags, TLS verification, certificate fingerprints and framing into typed immutable nodes and temporal relationships. Carry `request_index` and evidence reference on each 1xx relationship; store source tool + version and exact digest algorithm identifier. Map `redirect_blocked.reason` to local policy inference, not network observation.
3. **Confidentiality / missing evidence:** each of the six standard auth field values with a constant redaction marker means **presence and count observed, value unknown**. Never infer nonce equality, auth-scheme identity, credentials, exposure, credential replay or change events from identical v15 redacted observations. `header_bytes_b64` is post-redaction only. An independent raw capture, human authorization and protected handoff must be explicitly supplied to support value-level conclusions.
4. **Trust boundary:** a self-consistent digest is not a signature, an authorization statement, a verified time, or a confirmed vulnerability. Findings are unbound derived judgments. AI may propose questions or graph hypotheses but must not auto-confirm, invent evidence, bypass scope, lift confidence, or create observed edges without independently verified provenance.
5. **Future ProofGraph contracts:** signed local-first engagement manifests, trust anchors, actor/scope policy, clock/freshness semantics, contradiction and negative-evidence representations, schema migrations, portable replay, independently verifiable evidence attestations, and separate versioned adapters for ReconDiff/SurfaceMap/ScopeGuard/Evidence CLI/JSMap/ParamMiner-Go/AuthMatrix. Support only explicitly authorized synthetic/owned targets during development.

**No software adapter, graph core, attack-path engine or signed evidence bundle is claimed implemented here.**
